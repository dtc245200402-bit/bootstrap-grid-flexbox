# Bố cục 3 cột bằng Bootstrap Grid và Flexbox

Bài thực hành sử dụng Bootstrap 5.3.3 và Font Awesome 6.5.2.

## Nội dung đã triển khai

- Bootstrap Grid với 3 cột `col-md-4`.
- Flexbox căn giữa nội dung bằng `d-flex`, `justify-content-center`, `align-items-center`.
- Margin và padding bằng `my-5`, `py-5`, `p-4` và các lớp spacing khác.
- Display responsive: `d-none d-md-block` và `d-md-none`.
- Carousel có 3 slide, chỉ báo slide, nút chuyển và tự động chạy.
- Font Awesome icons trong navbar, các thẻ nội dung và form.
- Form liên hệ có kiểm tra họ tên, email và nội dung ở phía trình duyệt.
- CSS riêng để tinh chỉnh giao diện responsive.

## Chạy thử

1. Giải nén dự án.
2. Mở `index.html` bằng trình duyệt.
3. Cần kết nối Internet để tải Bootstrap, Font Awesome và ảnh carousel từ CDN.

Form chỉ kiểm tra dữ liệu phía trình duyệt, chưa gửi dữ liệu đến máy chủ.
